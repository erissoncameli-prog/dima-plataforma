Gestão + Inteligência

Gestão: as barras são as etapas do projeto, encadeadas no tempo como num cronograma, cada uma começando depois da anterior.
Inteligência: as linhas finas saem de cada etapa e convergem numa centelha luminosa: os dados de toda a execução viram um único sinal de decisão.
